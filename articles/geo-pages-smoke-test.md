# 蔬福安康 測試站 發佈測試：GitHub Pages 渠道

這篇是**蔬福安康 測試站**（lovegan.com.tw）GeoLook 看板的發佈渠道連線測試，用來確認「內容工作臺 → GitHub 倉庫 → Pages 公開網頁」這條路能通。

## 為什麼要放在 GitHub

AI 引擎要引用你，得先有一個公開、穩定、可被抓取的落點。GitHub Pages 提供一個不用另外架站就能公開的網址，文章上傳後即成為可被引用的來源。

## 這篇的用途

- 驗證 API 寫入、提交與 Pages 部署
- 之後真正要發的 GEO 文章會放在同一目錄 `articles/`

（本篇為測試站（lovegan.com.tw）的連線測試，不對外宣傳。）
